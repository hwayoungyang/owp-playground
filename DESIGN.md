# OWP Playground Design System

DataGrid refinement contract: Grid perimeter lines are owned by the native grid, while toolbar and status strips own their side edges; adjacent borders must remain one physical pixel. Summary sections have an explicit lower separator, using the native panel border token. All date, time and datetime columns center their values and headers. Time samples use input values at the same precision as the configured picker. Detail panels use three content regions: project summary, progress metrics and weekly chart; at narrow widths they stack and scroll inside the panel. Conditional background examples use blue and purple tokens, with labels that explain the applied rule. Sample project names are generic Korean domain names, preserved as sample data across language changes. Source snippets are the formatted executing TSX files, including column definitions, native props and Ref handlers.
