# OWP Playground Design System

DataGrid refinement contract: Grid perimeter lines are owned by the native grid, while toolbar and status strips own their side edges; adjacent borders must remain one physical pixel. Summary sections have an explicit lower separator, using the native panel border token. All example headers, including grouped headers and nested grids, are centered; body alignment follows each column. All date, time and datetime columns center their values and headers. Time samples use input values at the same precision as the configured picker. Detail panels use three content regions: project summary, progress metrics and weekly chart; at narrow widths they stack and scroll inside the panel. Conditional background examples use blue and purple tokens, with labels that explain the applied rule. Sample project names are generic Korean domain names, preserved as sample data across language changes. Source snippets are the formatted executing TSX files, including column definitions, native props and Ref handlers.

Chart and dark Grid corrections: Pareto draws its cumulative Line above the Bars through dataset order, keeps the0–100% cumulative axis, and reserves24px top padding plus8px of dataset clip overflow so the100% marker remains whole. The legend-position control reads 범례를 상단에 표시. Grouped stacks retains the native series legend and adds translated group numbers through its formatter only while grouped stacking is enabled; toggling the mode preserves series identity and visibility. Grid filter and enum menus use the preview palette's hover and subtle colors, with secondary-colored filter glyphs. Dark Grid borders lighten the palette's line color by24% while preserving its hue; shell borders remain unchanged and explicit theme overrides retain precedence. Stacked-series hide geometry remains package-owned.
