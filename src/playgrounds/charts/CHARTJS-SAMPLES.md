# Chart.js 공식 샘플 대응표

공식 샘플 75개의 대응 여부를 아래에 정리했습니다. 공식 샘플 외의 업무 예제와 Semi circle 등을 합쳐 유사 예제를 옵션으로 통합한 예제 메뉴 70개에서 구성 97개와 시작 가이드를 제공합니다. 애니메이션 전용 예제 6개는 사용자 요청으로 제외했습니다. 안내·utility 문서는 샘플 수에서 제외합니다.

공식 샘플 기준: 신규 40개, 기존 대응 9개, 대체·연관 예제 13개, 사용자 요청으로 제외 8개, 패키지 지원 필요 5개. 집계는 아래 검토한 Chart.js 소스 commit을 기준으로 하며, 실행 예제와 대응 상태의 원본은 [catalog.ts](./catalog.ts)와 [chartjsCoverage.ts](./model/chartjsCoverage.ts)입니다.

[공식 샘플 목록](https://www.chartjs.org/docs/latest/samples/information.html) · [검토한 소스](https://github.com/chartjs/Chart.js/tree/7169e65147a47f3720957a6f156a33c838ab9f57/docs/samples)

2026-10-22 검토 기준으로 예제는 설치된 정식 패키지 `@owp/charts 5.0.1`의 공개 API를 사용합니다. 의존성 버전은 [package.json](../../../package.json)에서 확인합니다. Bar·Line·복합 차트는 `ChartFrame preset="owp"`, Area·Box plot·Treemap·Radar·원형·Heatmap·Live는 전용 `Owp` 컴포넌트로 구성합니다. [Box plot](./examples/box-plot.tsx)·[Treemap](./examples/treemap.tsx)·[Heatmap](./examples/heatmap.tsx)은 기존 전용 컴포넌트와 `ChartFrame type="boxPlot"`·`type="treemap"`·`type="heatmap"`의 완전한 실행 소스를 코드 탭의 구성 방식에서 비교합니다. 예제 탭은 전용 컴포넌트를 실행합니다. Wrapper와 native 경로 모두 native 타입을 사용하며 `owpBoxPlot`·`owpTreemap`·`owpHeatmap` alias는 지원하지 않습니다. `createBoxPlotTooltipCallbacks(labels)`는 generic 인자 없이 사용합니다. Area는 native Filler, Radar는 native Radar controller와 RadialLinearScale을 사용합니다. 공장 데이터·OWP API 응답 변환·polling·샘플 조작 UI·카드 높이는 앱에서 처리합니다.

`ChartFrame`·`CoreChart`는 필요한 controller를 자동 등록합니다. Chart.js를 직접 생성하는 앱은 공개 `@owp/charts/chartjs/register`의 `registerChartCore()`를 먼저 호출합니다. Treemap의 native dataset은 `createTreemapData`, Heatmap의 native dataset은 `createHeatmapData`·`getHeatmapColor` 공개 유틸로 구성합니다. 기존 라인별 legend, tooltip, 타일·cell 설정과 animation을 유지하며 원본 실행 파일을 코드 탭에서도 제공합니다.

Live chart는 앱에서 1초 간격으로 새 값을 추가합니다. `OwpLiveChart`가 표시 구간을 1000ms linear로 이동해 데이터와 X축 시간 눈금·격자선을 함께 그리며, y는 실제 측정값을 유지합니다. 일시정지·탭 숨김·언마운트 시 갱신을 멈추고, 움직임 줄이기 설정에서는 즉시 갱신합니다.

## 공통 기능 반영 상태

막대 내부 라벨은 `createBarSegmentLabels`, palette는 `useChartPalette`와 `createChartColorMap`, 통계·전처리는 `summarizeBox`·`createHistogram`·`createPareto`·`downsampleMinMax` 공개 API를 사용합니다. 안정적인 series ID와 옵션·데이터 갱신 시 줌 범위 보존도 패키지에 반영됐습니다. 샘플에서는 업무별 입력 변환·표시 문자열과 조작 UI를 구성합니다.

Scatter·Bubble의 native controller는 패키지에 이미 등록돼 있습니다. [scatter](./examples/scatter.tsx)·[scatter-multi-axis](./examples/scatter-multi-axis.tsx)·[quadrants](./examples/quadrants.tsx)는 native `scatter`, [bubble](./examples/bubble.tsx)은 native `bubble`을 사용합니다. Bubble의 반경은 각 point의 `r`로 전달하며 크기 배율도 실제 데이터와 데이터 탭에 반영합니다.

[time-series](./examples/time-series.tsx)의 min/max 전처리는 패키지의 `downsampleMinMax`를 사용합니다. Native `Decimation` plugin은 등록돼 있지 않지만 현재 샘플은 공개 유틸로 처리하므로, 이를 위해 추가 패키지 지원이 필요하지는 않습니다.

## 패키지 지원과 전용 예제 상태

2026-10-21에 설치된 정식 패키지의 공개 export·declaration과 OWP 본체의 API 문서를 대조하고 아래 5개 공식 샘플의 전용 실행 예제를 추가했습니다. 각 예제는 기존 프레임·컨트롤·코드·데이터·이벤트 탭을 사용합니다.

| 기능 | 전용 예제 | 반영 내용 |
| --- | --- | --- |
| 시간축 | [time-line](./examples/time-line.tsx), [time-combo](./examples/time-combo.tsx), [time-max-span](./examples/time-max-span.tsx) | Luxon 초기화가 끝난 뒤 chart를 mount합니다. 불규칙 관측값의 time·timeseries 간격 비교, UTC 시간축 Column·Line, 최대 연결 시간에 따른 누락 구간을 표시합니다. |
| 로그축 | [log-scale](./examples/log-scale.tsx) | 양수 전력 측정값을 선형·로그 Y축으로 비교합니다. 로그축에 OWP `zoomSlider`를 사용하지 않습니다. |
| Subtitle | [subtitle](./examples/subtitle.tsx) | Canvas 부제목의 표시·여러 줄·정렬을 조절하고 PNG로 저장합니다. 접근성 이름에도 설명을 전달합니다. |

`registerChartTime()`은 `/chartjs/time` 전용 export이며 root·`/chartjs`·`/chartjs/register`에서는 제공하지 않습니다. Core만 등록하면 날짜 adapter는 자동으로 load되지 않습니다. 다른 Chart.js 날짜 adapter를 이미 사용하는 앱은 기존 초기화를 유지하고 이 helper를 호출하지 않습니다. Luxon helper는 같은 Chart.js instance의 전역 adapter를 교체하므로 다른 adapter와 혼용하지 않습니다.

Luxon 3.x와 `chartjs-adapter-luxon` 1.3.1 이상을 앱 의존성으로 설치했습니다. `TimeChart`는 시간축 예제를 열 때 초기화를 기다리고 실패하면 재시도할 수 있도록 합니다. 모든 새 시간축 예제는 epoch millisecond 입력과 UTC zone을 사용합니다.

일반 [date-time](./examples/date-time.tsx)·[time-series](./examples/time-series.tsx)는 계속 category 축을 사용합니다. `OwpLiveChart`의 timestamp 기반 창 이동도 native 시간축과 별도 계약입니다. 이 예제들을 위 시간축 공식 샘플의 전용 구현으로 집계하지 않습니다.

아래 5개 공식 샘플은 여전히 `unavailable`이며 패키지 지원 범위 확장이 필요합니다.

| 기능 | 관련 공식 샘플 | 현재 상태와 검토 범위 |
| --- | --- | --- |
| PolarArea | `other-charts/polar-area-center-labels`, `other-charts/polar-area`, `scriptable/polar` | `PolarAreaController`가 등록되지 않았습니다. 새 차트 유형의 데이터·범례·tooltip 계약을 함께 검토합니다. |
| Custom scale·controller | `advanced/derived-axis-type`, `advanced/derived-chart-type` | OWP 공개 API에 기반 클래스와 임의 등록 경로가 없습니다. `registerChartCore()` 공개와 별개로, 확장 API의 공개 범위를 먼저 정해야 합니다. |

## 연결된 브라우저에서 회귀 검사

`scripts/chart-browser-regressions.mjs`의 `runChartBrowserRegressions(tab, routes, capture)`는 이미 연결된 브라우저 tab과 실제 화면에서 수집한 sample route를 받습니다. Browser·dev server를 실행하거나 새 Chrome 프로세스를 만들지 않습니다. CUA tab의 `goto`·`playwright` 인터페이스 또는 같은 형태의 Playwright adapter를 전달합니다.

검사 항목은 외부 표시 off/on과 수동 숨김 유지, ring별 독립 항목, 가로형 행 tooltip, Heatmap 셀 좌표·값, Treemap 그룹 숨김·복구, Live 일시정지·입력·표시 수·재개입니다. 마지막에 Bar로 이동해 Live를 unmount합니다. `capture(name, tab)`은 각 시나리오의 screenshot 증거를 저장하는 필수 callback입니다. 연결된 IAB에서 별도로 수행한 화면 검사는 이 함수의 실행 결과와 구분해 기록합니다.
