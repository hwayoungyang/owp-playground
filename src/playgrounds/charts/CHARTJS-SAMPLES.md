# Chart.js 공식 샘플 대응표

공식 샘플 75개의 대응 여부를 아래에 정리했습니다. 공식 샘플 외의 업무 예제와 Semi circle 등을 합쳐 총 94개 예제와 시작 가이드를 제공합니다. 애니메이션 전용 예제 6개는 사용자 요청으로 제외했습니다. 안내·utility 문서는 샘플 수에서 제외합니다.

공식 샘플 기준: 신규 37개, 기존 대응 9개, 대체·연관 예제 11개, 사용자 요청으로 제외 8개, 패키지 지원 필요 10개.

[공식 샘플 목록](https://www.chartjs.org/docs/latest/samples/information.html) · [검토한 소스](https://github.com/chartjs/Chart.js/tree/7169e65147a47f3720957a6f156a33c838ab9f57/docs/samples)

예제는 설치된 `@owp/charts 4.0.0`의 공개 API를 사용합니다. Bar·Line·복합 차트는 `ChartFrame preset="owp"`, Area·Box plot·Treemap·Radar·원형·Heatmap·Live는 전용 `Owp` 컴포넌트로 구성합니다. Area는 native Filler, Radar는 native Radar controller와 RadialLinearScale을 사용합니다. Box plot·Treemap·Heatmap은 패키지 내부 controller와 element가 그리기와 hit test를 담당합니다. 공장 데이터·OWP API 응답 변환·polling·샘플 조작 UI·카드 높이는 앱에서 처리합니다.

Live chart는 앱에서 1초 간격으로 새 값을 추가합니다. `OwpLiveChart`가 표시 구간을 1000ms linear로 이동해 데이터와 X축 시간 눈금·격자선을 함께 그리며, y는 실제 측정값을 유지합니다. 일시정지·탭 숨김·언마운트 시 갱신을 멈추고, 움직임 줄이기 설정에서는 즉시 갱신합니다.

새 예제의 코드 탭에서 실행 원본을 확인할 수 있습니다. 공통 기본 스타일·범례·HTML 툴팁·반응형 설정은 `ChartFrame preset="owp"`가 제공합니다. Area·Box plot·Treemap·Radar·원형·Heatmap·Live는 `Owp*Chart` API를 사용합니다. `ChartCanvas.tsx`는 차트 높이, 데이터 탭과 이벤트 기록만 연결합니다.

공식 예제와 연결한 행은 동일한 설정 원리나 공개 확장 지점을 설명합니다. 원본의 모든 버튼·전환 상태를 복제한다는 뜻은 아닙니다. 범위는 각 행에 적었습니다.

## 연결된 브라우저에서 회귀 검사

`scripts/chart-browser-regressions.mjs`의 `runChartBrowserRegressions(tab, routes, capture)`는 이미 연결된 브라우저 tab과 실제 화면에서 수집한 sample route를 받습니다. Browser·dev server를 실행하거나 새 Chrome 프로세스를 만들지 않습니다. CUA tab의 `goto`·`playwright` 인터페이스 또는 같은 형태의 Playwright adapter를 전달합니다.

검사 항목은 외부 표시 off/on과 수동 숨김 유지, ring별 독립 항목, 가로형 행 tooltip, Heatmap 셀 좌표·값, Treemap 그룹 숨김·복구, Live 일시정지·입력·표시 수·재개입니다. 마지막에 Bar로 이동해 Live를 unmount합니다. `capture(name, tab)`은 각 시나리오의 screenshot 증거를 저장하는 필수 callback입니다. 연결된 IAB에서 별도로 수행한 화면 검사는 이 함수의 실행 결과와 구분해 기록합니다.
