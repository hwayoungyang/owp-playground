# 차트 비교 예제 자체 검토

- 그룹 식별자는 보존하고 한국어·영어 표시명만 변경했다.
- Histogram 원본 집계는 유지했다. 동일 폭 구간을 이웃한 사각 막대로 표현하며 축 제목을 표시한다.
- Small Multiples는 기본 6개, 3열×2행이다. 사이드바의 영향을 받는 카드 너비를 기준으로 2열·1열로 전환한다.
- Box plot 하단 누락의 원인은 Bar 기본 borderSkipped였다. false를 명시했고 여섯 그룹 상자의 양끝과 중앙값을 실제 픽셀로 검증했다.
- 범주 색상은 정렬 전에 원본 인덱스로 연결한다. Top N 개수 변경에도 같은 항목 색상이 유지된다. 공통 팔레트 기존 첫 여섯 색상은 유지하고 네 색상을 추가했다.
- 최종 build/check, 51개 단위 테스트, 83개 경로 검사와 별도 최종 6예제×3크기·영어·다크 QA가 통과했다. 전체 경로 검사는 최종 CSS 조정 전, 반응형 집중 검사는 최종 CSS 조정 후다.
- 스크린샷 자체 검토에서 수정 범위의 카드 잘림·내부 스크롤·가로 넘침을 찾지 못했다. 좁은 화면의 여섯 패널은 본문 세로 스크롤로 읽는다.
- 증거: `.omo/evidence/charts-comparisons/QA.md`. 독립 검토는 수행하지 않았다.
